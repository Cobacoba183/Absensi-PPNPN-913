Untuk Pegawai

  1. Isi Nama Pegawai dengan nama lengkap yang sama tiap hari.
  2. Pilih Masuk atau Pulang.
  3. Tekan 📷 Ambil Foto lalu izinkan kamera.
  4. Tunggu titik lokasi jadi hijau, izinkan akses lokasi kalau diminta.
  5. Tekan Catat Kehadiran. Data otomatis masuk ke Google Sheets milik admin.

Untuk Admin — Cara Setup (sekali saja)

  1. Buka Google Sheets, buat spreadsheet baru, beri nama misalnya "Data Absensi".
  2. Buka menu Extensions → Apps Script (Ekstensi → Apps Script).
  3. Hapus kode default, lalu tempel isi file Code.gs yang sudah disiapkan.
  4. Klik Deploy → New deployment. Pilih tipe Web app.
  5. Isi: Execute as = Me, Who has access = Anyone. Klik Deploy.
  6. Izinkan akses (Authorize access) saat diminta Google — ini akun Google Anda sendiri, aman.
  7. Salin Web app URL yang muncul (bentuknya seperti https://script.google.com/macros/s/xxxxx/exec).
  8. Buka file HTML ini di editor teks, cari baris const WEBAPP_URL = "..." di bagian paling atas <script>, tempel URL tadi di antara tanda kutip.
  9. Simpan file, lalu bagikan file HTML ini ke semua pegawai (lewat WhatsApp/email/host di GitHub Pages/dsb).
Setiap kali ada yang absen, satu baris baru otomatis muncul di sheet "Absensi": nama, jenis, tanggal, jam, koordinat, link peta, dan link foto ke Google Drive.

Untuk Admin — Cara Melihat Rekap

  • Buka spreadsheet "Data Absensi" kapan saja — datanya real-time, tidak perlu refresh apa pun di HTML.
  • Gunakan menu Data → Create a filter untuk menyaring per nama/tanggal/jenis.
  • Klik link di kolom Link Peta untuk buka lokasi absen di Google Maps.
  • Klik link di kolom Foto untuk lihat foto bukti absen di Google Drive.
  • Untuk rekap otomatis (misal total kehadiran per pegawai per bulan), buat Pivot table dari menu Insert → Pivot table.

Untuk Admin — Atur Radius Kantor & Jam Kerja

  1. Buka Apps Script, lihat bagian atas Code.gs yang bertuliskan KONFIGURASI.
  2. Matikan/hidupkan aturan terlambat: ubah ENABLE_LATE_RULE jadi true (aktif) atau false (nonaktif).
  3. Matikan/hidupkan pengecekan radius lokasi: ubah ENABLE_GEOFENCE jadi true/false dengan cara yang sama.
  4. Beberapa titik lokasi kerja: di OFFICE_LOCATIONS, setiap titik punya nama, lat, lng, dan radius sendiri. Absen dianggap sah kalau pegawai berada di dalam radius salah satu titik itu — cocok untuk kantor pusat, cabang, atau lokasi proyek yang berbeda-beda hari.
  5. Untuk menambah titik baru, salin format baris yang sudah ada, contoh:
    { name: 'Lokasi Proyek B', lat: -8.5, lng: 117.4, radius: 200 }, lalu pisahkan dengan koma dari titik sebelumnya.
  6. Koordinat tiap titik: buka Google Maps, klik-tahan lokasi di peta, koordinat muncul di kotak pencarian bawah — salin ke sini.
  7. REJECT_OUTSIDE_RADIUS: isi true untuk menolak absen di luar semua radius, atau false kalau tetap ingin disimpan tapi hanya ditandai "Di Luar Area".
  8. Setelah mengubah apa pun di sini, wajib Deploy ulang (Deploy → Manage deployments → pensil → New version → Deploy) agar berlaku.
Di Sheets akan muncul kolom Status Lokasi yang menyebutkan nama titik kantor mana yang cocok (mis. "Sah — Kantor Cabang A"), jadi admin tahu pegawai absen di titik mana.

Catatan

  • Halaman absen ini tidak butuh akun Claude sama sekali — bisa dibuka siapa saja lewat link/file HTML ini.
  • Karena backend-nya Google Apps Script milik admin sendiri, kapasitasnya sesuai kuota Google Drive/Sheets akun admin (biasanya sangat cukup untuk absensi tim kecil-menengah).
  • Untuk fitur lokasi, halaman ini perlu diakses lewat https:// (bukan dibuka sebagai file lokal) — hosting gratis seperti GitHub Pages, atau publish sebagai Claude artifact (tanpa storage, jadi tidak akan minta login), sudah cukup.
